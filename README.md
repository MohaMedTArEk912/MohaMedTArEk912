### Architecture

```text
index.html (SEO, Open Graph, JSON-LD, Base-Aware Boot Preloader)
   │
   ▼
src/main.tsx
   ├── default route ────────────► src/Portfolio.tsx
   │                                 Editorial landing page, case study dialogs, résumé
   │
   └── /comic/ ──────────────────► src/App.tsx
                                     ├── ComicBookFlipReader (8-volume illustrated spreads)
                                     └── lazy(src/ArchiveExtras.tsx)
                                           ├── CommandPalette (Ctrl+K) & Terminal CLI
                                           ├── 5 Engineering Arcade Mini-Games + Trophy Room
                                           ├── Executive 2D / Print ATS Résumé
                                           └── lazy(SceneContainer) ──► Three.js / R3F / GSAP / Lenis
```

### Workflows & Automation

- **Portfolio CI & GitHub Pages** ([`.github/workflows/portfolio-ci.yml`](.github/workflows/portfolio-ci.yml)): Runs Oxlint, TypeScript typechecking, subpath-safe Vite production build (`--base /MohaMedTArEk912/`), [`scripts/verify-pages-build.mjs`](scripts/verify-pages-build.mjs) asset/SEO verification, and deploys to GitHub Pages with a live smoke check.
- **Profile Activity Updater** ([`.github/workflows/update-readme.yml`](.github/workflows/update-readme.yml)): Keeps the Recent Public Activity block in sync via [`scripts/update-readme.mjs`](scripts/update-readme.mjs).
- **Contribution Snake** ([`.github/workflows/generate-snake.yml`](.github/workflows/generate-snake.yml)): Generates GitHub contribution snake animations.

### Local Development

```bash
git clone https://github.com/MohaMedTArEk912/MohaMedTArEk912.git
cd MohaMedTArEk912
npm ci
npm run dev
```

| Command | Description |
| :--- | :--- |
| `npm run dev` | Start Vite development server at `http://localhost:5173/` |
| `npm run lint` | Run Oxlint static analysis across the codebase |
| `npm run typecheck` | Run TypeScript project reference checks (`tsc -b`) |
| `npm run build` | Typecheck and build the production bundle into `dist/` |
| `npm run verify:pages -- --base /MohaMedTArEk912/` | Validate `dist/` assets, subpath links, and SEO tags |
| `npm run preview` | Preview the production build locally |
